FinKit 編輯與內容政策

最後更新：2026-09-15

FinKit 是一個以台灣使用者為主要對象的理財工具與知識網站。網站的目標不是用大量頁面搶搜尋流量，而是把常見財務問題轉成可檢查的假設、公式、案例與工具，讓使用者知道「這個數字怎麼來」以及「什麼情況不能只看這個數字」。

我們如何決定要發布什麼

FinKit 優先處理可以明確定義、能用公式或公開規則驗證，且對台灣使用者有實際決策價值的主題，例如現金流、負債、房貸、退休、交易成本、海外所得與最低稅負。單純追逐熱門關鍵字、沒有額外分析價值或只有改寫他站內容的頁面，不是本站的內容方向。

資料來源與查核原則

  • 法規、稅務、健保與政府制度：優先使用財政部、國稅局、健保署、主管機關或其他第一手公開資料。
  • 金融商品條款：以發行機構、公開說明書、交易所或正式文件為優先來源。
  • 市場或匯率資料：頁面會標示資料來源與用途，公開 API 僅作參考值時會明確註明。
  • 所有試算都會區分「公式結果」與「實際決策」，避免把模型輸出寫成保證或個別建議。

自動化與 AI 輔助

FinKit 可能使用程式、自動化流程或 AI 協助整理草稿、檢查格式、產生測試案例與改善文字可讀性；但發布內容仍以本站定義的公式、資料來源、假設與編輯規則為準。對稅務、費率、門檻與金融計算等可驗證資訊，會優先回到官方或第一手資料核對。

我們不把「自動產生很多頁面」視為內容價值。 工具頁必須有實際用途、判讀方式、案例與限制；文章頁必須能回答具體問題，而不是只堆疊關鍵字。

更新頻率

會隨年度調整的內容，例如綜合所得稅、最低稅負、健保補充保費或交易制度，在已知官方新年度規則後更新。市場價格、匯率等變動資料會依工具標示的更新方式處理。長期理財觀念則在公式、制度或主要假設改變時重新檢視。

勘誤與更正

如果發現公式、法規年度、門檻、文字敘述或資料來源有誤，可透過 聯絡頁 或 GitHub issue 回報。若錯誤會影響試算結果，修正優先級高於新增功能。

利益與限制

FinKit 提供教育與試算用途，不以工具結果取代會計師、稅務代理人、律師、保險或投資專業人員的個別建議。網站可能透過 Google AdSense 等廣告服務取得營收，但廣告不會決定公式、結論或內容排序。
