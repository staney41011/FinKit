聯絡與勘誤

如果你發現公式、年度規則、連結、文字或操作有問題，FinKit 希望收到可重現的錯誤資訊。

如何回報

請透過 FinKit 的 GitHub 專案提出 issue。描述工具名稱、輸入數字、你預期的結果與實際結果；若是畫面問題，附上瀏覽器與截圖會更容易定位。

稅務與年度規則

若回報稅務、健保或法規數字，請盡量附主管機關公告名稱或連結，方便核對適用年度。

不處理的內容

FinKit 無法透過網站替個別使用者做正式報稅、代替金融機構核保核貸、或保證特定投資結果。

安全問題

若你發現可能造成資料外洩、惡意注入或網站安全問題，請避免公開貼出敏感資料，並在 GitHub 問題中只提供必要的重現資訊。
